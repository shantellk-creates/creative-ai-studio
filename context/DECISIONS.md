# DECISIONS.md — Decision Log

This file is the persistent record of settled strategic and operational
decisions for the AI Creative Studio. Its purpose is to stop the same
decisions from being re-litigated repeatedly across sessions and agents.

**Rule for agents:** before proposing or re-deciding something that affects
the business model, Creator-001, Higgsfield usage policy, or operating model,
check this log first. If it's already settled here, follow it — don't reopen
it without the Founder explicitly revisiting the decision.

## How to add a decision

Append a new entry at the bottom using the template below. Do not edit or
delete past entries to change history — if a decision is later reversed or
superseded, add a new entry that says so and references the original by date.

```
### YYYY-MM-DD — <Short decision title>

**Decision:** What was decided, stated plainly.

**Context:** Why this came up / what problem it addresses.

**Made by:** Founder / Creative Director (or who had authority to decide).

**Status:** Active | Superseded by <date/title>
```

### 2026-09-13 — Repository foundation structure established

**Decision:** Created the initial AI Creative Studio repository foundation:
`CLAUDE.md`, `AGENTS.md`, the `context/` directory (MASTER-CONTEXT,
CURRENT-STATE, BUSINESS-MODEL, CREATOR-SPEC, HIGGSFIELD-RULES, DECISIONS), and
empty scaffolding for `creators/creator-001/`, `content/` (ideas, briefs,
prompts, generated, approved), and `assets/` (references, final). No
application code, website, SaaS, portal, automation, or additional
infrastructure was built.

**Context:** Needed a persistent, agent-readable source of truth before any
creative or commercial work begins, per the operating model (git repository =
institutional memory).

**Made by:** Founder / Creative Director (via Claude Code, primary
builder/operator).

**Status:** Active

### 2026-09-13 — September 2026 revenue objective set

**Decision:** The Studio's immediate objective is **£1,000+ actual cash
collected by 30 September 2026**. Only actual collected cash counts — views,
followers, likes, enquiries, proposals, invoices sent, and pipeline are
explicitly excluded from counting toward this target.

**Context:** Establishes a concrete, time-boxed, unambiguous success
criterion for the current phase of the Studio, ahead of any creator
definition or content production.

**Made by:** Founder / Creative Director.

**Status:** Active

### 2026-09-13 — Higgsfield not yet activated

**Decision:** Higgsfield trial/account will not be activated and no credits
will be spent as part of building the repository foundation. Any future
generation requires the full approval protocol in
`context/HIGGSFIELD-RULES.md`.

**Context:** Protects the scarce Higgsfield credit resource and keeps
generation activity strictly Founder-gated from the outset.

**Made by:** Founder / Creative Director.

**Status:** Active

### 2026-09-13 — Prove one creator before scaling

**Decision:** Only one AI creator (Creator-001) will be developed at this
stage. No additional creators will be created until Creator-001 is proven
(i.e. has produced real, collected revenue).

**Context:** Core Principle — revenue before infrastructure, prove one strong
AI creator before creating multiple creators. Avoids diluting effort/credits
across unproven personas.

**Made by:** Founder / Creative Director.

**Status:** Active
